# wordbook

토익 빈출 단어를 세트로 나눠 외우고, 잊을 때쯤 다시 물어봐주는 CLI 앱.
단어를 직접 넣지 않아도 공개 단어장 **4,059개**가 들어 있고, AI가 영어 예문 퀴즈를 만들어준다.

## 어떻게 외우게 되나

0. 외우는 순서는 **토익 빈출 단어(TSL 1,250개) 먼저**, 그다음 NGSL 단어다.
   `the`, `say` 같은 기초 단어는 기본으로 **NGSL 1,500위까지 건너뛴다** (외울 단어 약 2,550개).
   이 기준은 진도 보기의 설정에서 바꿀 수 있고, 0으로 두면 4,059개를 전부 외운다.
1. **50단어 세트**를 **공부한 날 기준 3일** 동안 외운다 (하루 빠져도 세트가 날아가지 않는다).
2. 세트를 시작할 때 단어 50개를 뜻과 함께 보여준다. **이미 아는 단어** 번호를 쉼표로 적으면
   바로 졸업 처리되고, 그만큼 새 단어로 채워진다 (엔터만 치면 전부 외운다).
3. 하루하루 문제 종류가 달라진다: **1일차 뜻 고르기 → 2일차 영어 쓰기 → 3일차 예문 빈칸**.
   예문 빈칸 문제는 2일차 공부가 끝난 뒤에 AI가 미리 만들어둔다.
4. 세트가 끝나면 **마지막 2번 연속 정답인 단어는 통과**해서 복습 대기열로, 나머지는 다음 세트로 이월된다.
5. 복습은 **3일 → 7일 → 14일 → 30일 → 60일** 간격으로 점점 길어지고, 60일까지 맞히면 **졸업**이다.
   복습에서 틀리면 다음 세트에서 다시 외운다. 하루 복습은 최대 30개.
   복습 문제는 단계마다 종류가 바뀐다(예문 빈칸 → 영어 쓰기 → 뜻 고르기 → 다시 처음).
   같은 예문을 반복해서 보면 단어가 아니라 문장을 외워버리기 때문이다.

## 처음 실행하기 전에 (한 번만)

1. **가상환경 만들기** (이미 `.venv`가 있으면 건너뛰기)
   ```
   python -m venv .venv
   ```

2. **필요한 패키지 설치**
   ```
   .venv\Scripts\pip install langchain langchain-openai python-dotenv pytest openpyxl
   ```

3. **API 키 설정** — 프로젝트 루트에 `.env` 파일을 만들고 아래처럼 채운다.
   (`.env`는 `.gitignore`에 있어서 깃에 올라가지 않는다.)
   ```
   OPENAI_API_KEY=sk-여기에_실제_키
   ```

## 사용 방법

프로젝트 루트(이 폴더)에서 인자 없이 실행하면 번호로 고르는 메뉴가 뜬다.
```
.venv\Scripts\python.exe .
```
```
========================================
  wordbook
========================================

  1. 오늘의 학습
  2. 내 단어 추가
  3. 진도 보기
  4. 목록 보기
  5. 종료

번호 입력 >
```

- **1. 오늘의 학습** — 오늘 풀 문제를 차례로 낸다. 복습할 단어를 먼저 내고, 그다음
  이번 세트 단어를 그날 차수에 맞는 종류로 낸다. 세트가 없거나 3일을 다 채웠으면 알아서 마감하고
  새 세트를 시작한다.
  - 뜻 고르기: 보기 **번호**를 입력
  - 영어 쓰기: **영어 단어를 타이핑** (대소문자·앞뒤 공백은 무시)
  - 예문 빈칸: 보기 4개 중 **번호 또는 영어 단어**로 입력
  - 문제가 이상하면 답 대신 **`?`** 를 입력한다. 신고한 예문 퀴즈는 버리고 다음에 새로 만든다.
  - 예문 퀴즈는 **2일차 공부를 마친 뒤에** 미리 만든다(50개면 6분쯤). 1일차와 3일차는 기다림이 없다.
    미리 만들지 못한 단어가 있으면 그 문제만 영어 쓰기로 대신 낸다.
- **2. 내 단어 추가** — 단어장에 없는 단어도 직접 넣을 수 있다. 넣은 단어는 다음 세트에 먼저 나온다.
  잘못 눌렀으면 **`0`** 을 치면 저장하지 않고 메뉴로 돌아간다.
- **3. 진도 보기** — 전체 중 몇 단어를 졸업했는지, 복습 중인 단어, 아직 안 본 단어, 지금 속도로 계산한
  예상 완주일을 보여준다. 신고한 문제가 있으면 개수도 같이 보여준다.
  그 아래에서 **설정**(한 세트 단어 수, 세트당 일수, 하루 복습 수, 기초 단어 건너뛰기)을 바꿀 수 있다.
- **4. 목록 보기** — 2번으로 직접 넣은 단어 목록을 보여준다 (예전 `words.json` 단어도 여기 합쳐진다).
  **번호를 치면 그 단어를 지운다** (잘못 넣었을 때). 그냥 엔터를 치면 아무것도 안 지우고 돌아간다.
- **5. 종료**

학습은 문제를 하나 풀 때마다 자동 저장되므로, 중간에 창을 닫아도 푼 것까지는 남는다.

메뉴를 고를 때마다 화면이 지워지므로, 목록을 본 다음 문제를 풀어도 답이 화면에 남아 있지 않다.
기능 하나가 끝나면 **엔터**를 눌러야 메뉴로 돌아간다.

## 데이터

| 파일 | 내용 | 깃에 올라가나 |
|---|---|---|
| `data/word_bank.json` | 고정 단어장 4,059개 (단어, 한국어 뜻, 품사, 출처, 순위) | 올라감 |
| `progress.json` | 내 학습 기록 (세트, 복습 단계, 다음 복습일, 미리 만든 퀴즈) | 안 올라감 (개인 기록) |
| `words.json` | v1에서 쓰던 단어 파일. 앱을 처음 켤 때 자동으로 "내 단어"로 옮겨진다 | 올라감 |
| `data/source/` | 원본 NGSL·TSL 파일 4개와 출처 표기(`SOURCE.md`) | 올라감 |
| `data/meaning_fixes.json` | AI가 만든 뜻 중 아쉬운 것을 손으로 고쳐둔 목록 | 올라감 |
| `data/meanings_cache.json` | 단어장을 다시 만들 때 쓰는 뜻 캐시 | 안 올라감 |

데이터베이스는 쓰지 않는다. 다른 컴퓨터로 옮길 때는 `progress.json`을 직접 복사하면 된다.

## 단어장 다시 만들기 (보통은 할 일 없음)

`data/word_bank.json`은 이미 만들어져 있다. 원본에서 다시 만들려면:
```
.venv\Scripts\python.exe scripts\build_word_bank.py
```
원본 엑셀·CSV를 읽어 합치고, AI로 한국어 뜻을 채워 저장한다. 200단어마다 캐시에 저장하므로
중간에 끊겨도 다시 실행하면 이어서 받는다.

## 알려진 한계

- AI가 만든 한국어 뜻은 40단어에 1개꼴로 아쉬운 것이 섞인다. 눈에 띈 것은 `data/meaning_fixes.json`에
  적어두면 단어장을 다시 만들어도 고친 뜻이 유지된다 (지금 4단어: present, charge, preliminary, clap).
- 예문 퀴즈는 오답끼리 뜻이 뭉치면(청구하다/청구서처럼) 코드가 걸러서 다시 만든다. 다만 단어장에
  없는 단어가 오답으로 나오면 뜻을 몰라서 검사하지 못한다 (예: late와 tardy가 같이 나온 경우).
  이상한 문제를 만나면 답 대신 `?` 를 입력하면 신고되고, 그 퀴즈는 다음에 새로 만든다.
- 자세한 내용은 `TASKS.md`의 24번·35번 항목에 적어뒀다.

## 프로젝트 문서

- `spec.md` — 무엇을 만드는지 (v2 스펙)
- `prd.md` — 기능 목록과 기술 결정(왜 그렇게 했는지)
- `TASKS.md` — 작업을 조각으로 쪼갠 목록과 완료 현황
- `CLAUDE.md` — 이 프로젝트에서 항상 지키는 규칙
- `rubric/` — AI 심판이 품질을 채점할 때 쓰는 채점표

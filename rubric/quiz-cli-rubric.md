# 퀴즈 CLI 실행 흐름 채점표 (quiz-cli-rubric)

`wordbook quiz` 명령어를 실제 LLM 연결 상태로 한 번 실행한 결과를 평가할 때 쓰는 채점표.
TASKS.md 13번 "wordbook quiz 실제 사용 흐름 확인"에서 AI 심판이 이 표를 기준으로 채점한다.
`rubric/quiz-rubric.md`(퀴즈 문제 자체의 품질)와는 별개로, **CLI 실행 흐름과 채점 정확성**을 본다.

## 채점 항목 (각 5점 만점)

| # | 항목 | 무엇을 보는가 | 감점 기준 |
|---|------|--------------|-----------|
| ① | 실행 성공 | 에러 없이 처음부터 끝까지 실행되는가 | 예외 발생, 크래시면 대폭 감점 |
| ② | 문제 출력 | 예문과 보기 4개가 사용자에게 명확하게 보이는가 | 형식이 깨지거나 보기가 안 보이면 감점 |
| ③ | 채점 정확성 | 사용자가 입력한 답과 정답을 비교해 맞음/틀림 판정이 실제로 정확한가 | 맞는 답인데 틀렸다고 하거나 그 반대면 대폭 감점 |
| ④ | 결과 반영 | `words.json`에 `wrong_count`/`last_wrong_date`가 채점 결과에 맞게 반영됐는가 | 반영 안 되거나 반대로 반영되면 대폭 감점 |
| ⑤ | 사용자 피드백 | 맞았는지 틀렸는지, 정답과 해설을 사용자가 볼 수 있게 알려주는가 | 결과를 화면에 안 알려주고 조용히 끝나면 감점 |

## 합격선

**모든 항목이 4점 이상이어야 합격한다.**

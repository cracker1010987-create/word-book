# 내 단어장 넣는 곳

이 폴더에 CSV 파일을 넣으면 앱의 **4번 단어장** 메뉴에 나타난다.
**파일 이름이 단어장 이름**이 된다 (`내신1과.csv` → "내신1과").

## 파일 형식

한 줄에 `단어,뜻` 을 적는다. 뜻 뒤에 품사를 적어도 된다.

```
word,meaning
abolish,폐지하다
adolescent,청소년
benevolent,자비로운,adjective
```

- 첫 줄이 `word,meaning` 같은 제목 줄이면 알아서 건너뛴다.
- 빈 줄, 뜻이 없는 줄은 건너뛴다.
- 엑셀로 저장한 CSV(맨 앞에 BOM이 붙는 파일)도 읽는다.
- 한국어가 깨지면 **UTF-8**로 저장해달라.

## 넣는 방법 두 가지

1. 이 폴더에 파일을 직접 복사한다.
2. 앱에서 `4번 단어장` → `a` → 파일 경로와 이름을 입력한다 (여기로 복사된다).

## 알아둘 것

- 학습 기록(세트·복습·진도)은 **단어장마다 따로** 쌓인다. 단어장을 바꿔도 서로 섞이지 않는다.
- 단어장을 지워도 그 단어장의 학습 기록은 남는다. 같은 이름으로 다시 넣으면 이어서 할 수 있다.
- 기본 단어장("토익", 4,059단어)은 지울 수 없다.
